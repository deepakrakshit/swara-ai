1. Overview
Mangalore Refinery and Petrochemicals Limited (MRPL), under MoPNG, requires an agentic AI workbench that drafts engineering documents (corrosion-trend memos, inspection summaries, SOP-grounded reports) from refinery records — P&ID scans, inspection PDFs, spreadsheets — entirely on-premise and entirely air-gapped. No cloud LLM, no external endpoint, no telemetry. Sovereignty is demonstrated as proof (kernel-level egress drops on IPv4 and IPv6, SHA-256 weight provenance, a live packet counter at zero), not as policy text.
Flagship demo task: "Draft the Q3 corrosion-trend memo for Unit 200, cite the inspection SOP." with an uploaded P&ID scan + inspection PDF. Output is an executive-ready `.docx` rendered from `assets/mrpl_template.dotx`, with embedded P&ID thumbnails, a generated trend chart, and resolvable `[SOP-REF §X.X p.Y]` citations — approved by a human engineer via HITL before disk write.

5. Core Subsystems
5.1 Dynamic Task Router
Three layers, cheapest first. Every decision is emitted as an SSE `[ROUTE]` trace line.
| Layer|Logic|Latency Target|Purpose|
| ---|---|---|---|
| L1 — Deterministic fast-path|File MIME (image/* → Vision; .xlsx/.csv → Coder) + prompt regex for explicit calculation/math intents + ingestion density/gibberish outcome|< 5 ms|Zero-inference dispatch for unambiguous inputs|
| L2 — Brain-7B constrained judge|Qwen2.5-7B emits a fixed-schema JSON route decision (temperature 0, max_tokens 64)|< 1500 ms|Ambiguous mixed-intent requests; realistic prefill target for 7B without continuous batching (the earlier < 120 ms target was abandoned)|
| L3 — Manual override|UI dropdown selects the specialist explicitly|immediate|Fallback; full operator control|
Unhandled requests always fall through to L3 — the router never blocks the user.
Router reference implementation (v5.0 restored fenced block):

```python
import re

CALC_RE = re.compile(r"\b(calculate|compute|trend|rate|delta)\b", re.I)

def route_l1(mimes, names, prompt, page_outcome):
    """Deterministic fast-path (< 5 ms). Returns (specialist, trace)."""
    if any(m.startswith("image/") for m in mimes):
        return "vision", "L1 MIME image/* -> Vision"
    if any(n.lower().endswith((".xlsx", ".csv")) for n in names):
        return "coder", "L1 MIME spreadsheet -> Coder"
    if CALC_RE.search(prompt):
        return "coder", "L1 regex math-intent -> Coder"
    if page_outcome in ("blank", "scanned", "gibberish"):
        return "vision", "L1 density/gibberish -> Vision OCR"
    return None, "L1 no-match -> L2"

def route_l2(prompt, brain_client):
    """Brain-7B constrained JSON judge (temperature 0, max_tokens 64, < 1500 ms)."""
    decision = brain_client.chat(
        prompt=prompt, temperature=0.0, max_tokens=64,
        response_schema={"specialist": ["vision", "rag", "coder", "brain"]},
    )
    return decision["specialist"], f"L2 Brain-7B judge -> {decision['specialist']}"
```

5.2 Agentic Loop & Loop-Killer
LangGraph ReAct loop: Plan → ToolCall → Observe → Reflect → (repeat | Finalize). Budgets: 10 steps / 240 s per task. An Observation Truncation Filter caps tool output at ≈ 1500 characters so a rogue `print(df)` cannot blow the 8k Brain context.
Loop-killer (syntax-verified, executed without error in the v5.0 dry-run — Appendix D):

```python
import hashlib
import json

def hash_observation_tail(toolname: str, args: dict, observation: str) -> str:
    # Hash the TAIL: tracebacks share identical prefixes;
    # the distinguishing error text lives at the end.
    # sort_keys=True guarantees deterministic serialization.
    payload = toolname + json.dumps(args, sort_keys=True) + observation[-500:]
    return hashlib.sha256(payload.encode()).hexdigest()
```

Repeated tail-hashes within a task force an immediate route-break / repair prompt. LangGraph state-hash deduplication catches graph-level infinite loops.

5.3 Sovereign RAG & Multimodal Ingestion
Flow: upload (PDF / P&ID scan / XLSX / CSV) → pdfplumber extraction → density gate + gibberish filter → clean text pages take the text path (tables extracted first and stored as intact Markdown chunks; body chunked at 1000–1200 tokens → nomic embed :8083 → ChromaDB); blank / scanned / gibberish pages are rasterized to PNG and OCR'd by the Vision model (equipment tags + bounding boxes → SQLite `pid_tags`: tag ↔ page ↔ bbox ↔ thumbnail).
Density gate + gibberish filter (math-safe, syntax-verified, executed without error in the v5.0 dry-run — Appendix D):

```python
import re

def is_gibberish_or_blank(text: str) -> bool:
    # Guard: blank/empty pages — prevents ZeroDivisionError downstream
    if not text or not text.strip():
        return True
    stripped = text.strip()
    # Guard: extremely short pages cannot yield a reliable ratio
    if len(stripped) < 50:
        return True
    # Gibberish regex filter: null/control bytes, non-printable chars
    if re.search(r'[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]', stripped):
        return True
    # Alpha ratio check (math-safe: len(stripped) is >= 50 here)
    alpha_count = sum(c.isalpha() or c.isspace() for c in stripped)
    ratio = alpha_count / len(stripped)
    return ratio < 0.40
```

| Decision|Mechanism|Problem Solved|
| ---|---|---|
| Table preservation|pdfplumber table extraction before chunking; tables stored as intact Markdown|Numerical relationships survive embedding|
| P&ID thumbnail cropping|On retrieval hits (e.g., "Pump P-101A"), stored bbox crops a thumbnail embedded in the report|Visual verification of cited components|
| Citation contract|Every RAG-grounded sentence ends with [SOP-REF §X.X p.Y]; Reflect regex-validates; missing tags block finalization → repair prompt|Grounded, auditable output|
| Embedding window|nomic-embed-text-v1.5 supports 8192 tokens vs 1000–1200 token chunks|Large truncation safety margin|


6. Sovereignty Monitor
6.1 The SOVEREIGN_EGRESS Chain + IPv6 Backstop (syntax-verified, executed without error in the v5.0/v5.2 dry-runs — Appendix D)
Raw `iptables -I OUTPUT 1 …` inserts are not used: Docker dynamically rewrites its own chains on daemon reload and silently displaces index-based inserts. v2+ uses a dedicated chain — only the two jump rules are index-sensitive, and a watchdog re-asserts them every 5 s. The chain name is `SOVEREIGN_EGRESS` (with underscore) in every command below; v4.0 eliminates the `-N SOVEREIGNEGRESS` mismatch flagged by the final audit; v5.0 restores this block as a fenced script and makes jump-pinning idempotent and displacement-safe; v5.2 adds the IPv6 backstop.

```bash
#!/usr/bin/env bash
# sovereignty_firewall.sh — run as root at boot; watchdog re-asserts jumps every 5s
set -euo pipefail

NIC="eth0"
PEERS=("10.0.99.10" "10.0.99.11")        # whitelisted internal peers — adjust per deployment

# ---- IPv4: dedicated chain (flush-and-rebuild is idempotent) ----
iptables -N SOVEREIGN_EGRESS 2>/dev/null || iptables -F SOVEREIGN_EGRESS
iptables -A SOVEREIGN_EGRESS -o lo -j ACCEPT
iptables -A SOVEREIGN_EGRESS ! -o "${NIC}" -j ACCEPT
for p in "${PEERS[@]}"; do
    iptables -A SOVEREIGN_EGRESS -o "${NIC}" -d "${p}/32" -j ACCEPT
done
iptables -A SOVEREIGN_EGRESS -j LOG --log-prefix "[AIRGAP-EGRESS-DROP] " --log-level 4
iptables -A SOVEREIGN_EGRESS -j DROP
for chain in FORWARD OUTPUT; do
    while iptables -C "${chain}" -j SOVEREIGN_EGRESS 2>/dev/null; do
        iptables -D "${chain}" -j SOVEREIGN_EGRESS
    done
    iptables -I "${chain}" 1 -j SOVEREIGN_EGRESS
done

# ---- IPv6 backstop: deny-by-default (primary control is sysctl disable_ipv6=1, §6.6) ----
ip6tables -N SOVEREIGN_EGRESS6 2>/dev/null || ip6tables -F SOVEREIGN_EGRESS6
ip6tables -A SOVEREIGN_EGRESS6 -o lo -j ACCEPT
ip6tables -A SOVEREIGN_EGRESS6 -j LOG --log-prefix "[AIRGAP-EGRESS6-DROP] " --log-level 4
ip6tables -A SOVEREIGN_EGRESS6 -j DROP
for chain in FORWARD OUTPUT; do
    while ip6tables -C "${chain}" -j SOVEREIGN_EGRESS6 2>/dev/null; do
        ip6tables -D "${chain}" -j SOVEREIGN_EGRESS6
    done
    ip6tables -I "${chain}" 1 -j SOVEREIGN_EGRESS6
done
```

IPv6 posture (v5.2): the primary control is kernel disable via /etc/sysctl.d/99-sovereign-ipv6.conf containing `net.ipv6.conf.all.disable_ipv6 = 1` and `net.ipv6.conf.default.disable_ipv6 = 1`, applied at boot before any daemon starts. The `SOVEREIGN_EGRESS6` chain is a deny-by-default backstop covering the boot window and any misconfiguration that re-enables IPv6. Preflight asserts both layers (§6.6); the Test Egress button probes an IPv6 target live (§6.5).
Design consequence: unlisted subnet IPs (e.g., 10.0.99.254) are dropped by the same chain — which makes the lateral Test Egress probe honest (§6.5). Chain contents are immune to Docker reordering; the watchdog guarantees the jump rules stay pinned at position 1 in both families. Acceptance check after boot: `iptables -L SOVEREIGN_EGRESS -n -v` and `ip6tables -L SOVEREIGN_EGRESS6 -n -v` show populated chains and non-zero drop counters after probes.

6.2 Buffered tcpdump Packet Counter
A background service runs `tcpdump` on the physical NIC with the `-l` flag (line-buffering) so packets aren't delayed in C-library memory blocks. The UI updates every 500 ms: `Outbound packets on eth0: 0`.
Counter service (v5.0 restored fenced block):

```bash
#!/usr/bin/env bash
# egress_counter.sh — line-buffered outbound packet counter; UI polls the file every 500 ms
set -euo pipefail
NIC="eth0"
OUT=/srv/sovereign/metrics/egress_count
echo 0 > "${OUT}"
tcpdump -l -Q out -i "${NIC}" -n 2>/dev/null | while IFS= read -r pkt; do
    printf '%d\n' $(( $(cat "${OUT}") + 1 )) > "${OUT}"
done
```

6.5 Tri-Probe "Test Egress" Interaction
A UI button fires deliberate outbound attempts from the backend against three targets — a skeptical MoPNG judge asking "what about exfiltration to the local subnet, or over IPv6?" gets a live answer:
| Probe|Target|Expected result|
| ---|---|---|
| External IPv4|8.8.8.8:53|LOG+DROP by SOVEREIGN_EGRESS; [AIRGAP-EGRESS-DROP] streamed to UI|
| Lateral IPv4|10.0.99.254 (unassigned subnet IP)|LOG+DROP — not a whitelisted peer|
| External IPv6|2001:4860:4860::8888:53|Fails fast with OSError while disable_ipv6=1; if IPv6 were ever re-enabled, LOG+DROP by SOVEREIGN_EGRESS6; [AIRGAP-EGRESS6-DROP] streamed|

```python
import socket
from orchestrator import stream_sse, DemoStopError
# stream_sse() and DemoStopError are provided by the FastAPI orchestrator runtime.

def run_test_egress():
    probes = [
        ("8.8.8.8",              53,  "external DNS (IPv4)"),
        ("10.0.99.254",          445, "lateral — unassigned subnet IP (IPv4)"),
        ("2001:4860:4860::8888", 53,  "external DNS (IPv6)"),
    ]
    for ip, port, label in probes:
        try:
            socket.create_connection((ip, port), timeout=0.3)   # 300 ms hard timeout
            raise DemoStopError(f"EGRESS SUCCEEDED to {label}")  # never expected
        except (TimeoutError, OSError):
            # IPv4 probes: dropped by SOVEREIGN_EGRESS -> timeout path.
            # IPv6 probe: with disable_ipv6=1 this fails fast (EAFNOSUPPORT /
            # ENETUNREACH); if IPv6 were ever re-enabled, SOVEREIGN_EGRESS6
            # drops it -> timeout path. Every outcome reports "blocked".
            stream_sse("egress_blocked", target=f"{ip}:{port}", label=label)
            # UI simultaneously renders the matching [AIRGAP-EGRESS*-DROP] kernel log line
```

Each socket uses a strict 300 ms timeout so the UI never hangs. The backend catches `TimeoutError`/`OSError` (`socket.timeout` is a deprecated alias and is not used) and immediately streams the matching kernel drop log to the frontend. The packet counter stays at 0 in all three cases.

6.6 Boot Preflight (preflight.sh v5.2)
Boot is demo-ready only when every gate below passes; a non-zero exit blocks demo mode. This is the single executable source of truth for the Hour 0–2 build block (§12) and for the ARCHITECTURE doc §17.

```bash
#!/usr/bin/env bash
# preflight.sh — boot-time sovereignty gates; non-zero exit blocks demo mode
set -euo pipefail

for v in ANONYMIZED_TELEMETRY HF_HUB_OFFLINE TRANSFORMERS_OFFLINE PIP_DISABLE_PIP_VERSION_CHECK; do
    [ -n "${!v:-}" ] || { echo "FAIL env ${v} unset"; exit 1; }
done
for h in huggingface.co cdn-lfs.huggingface.co api.github.com github.com pypi.org files.pythonhosted.org; do
    grep -q "127.0.0.1 ${h}$" /etc/hosts || { echo "FAIL hosts blackhole ${h}"; exit 1; }
done
iptables -L SOVEREIGN_EGRESS -n -v >/dev/null
[ "$(iptables -L FORWARD -n --line-numbers | awk '$1=="1"{print $2}')" = "SOVEREIGN_EGRESS" ]
[ "$(iptables -L OUTPUT  -n --line-numbers | awk '$1=="1"{print $2}')" = "SOVEREIGN_EGRESS" ]
pgrep -f sovereignty_watchdog.sh >/dev/null
```

7. User Interface & UX
Single Unified Codebase: Built exclusively in React 18 + Vite with Tailwind CSS.
Zero-CDN Architecture: The production build (`vite build`) produces a static `/dist` directory served directly via FastAPI. `preflight.sh` runs a `grep -R` for `googleapis`, `unpkg`, `jsdelivr` to guarantee no external assets are requested during the demo.
SSE Streaming Fixes (HARDENED): The FastAPI `/stream` endpoint includes reverse-proxy-safe headers (`X-Accel-Buffering: no`, `Cache-Control: no-cache`, `Content-Encoding: identity`) so agent thoughts stream character-by-character. `GZipMiddleware` is explicitly not registered — gzip buffers the stream and causes burst-at-the-end failures; any fronting proxy must also have gzip off for `/stream`.
Sovereignty Dashboard: live eth0 packet counter (500 ms refresh), `[AIRGAP-EGRESS-DROP]` / `[AIRGAP-EGRESS6-DROP]` kernel log streams, SHA-256 weight manifest, and the tri-probe Test Egress button (§6.5).
Polished Deliverables: The python-docx and openpyxl exporters use pre-styled corporate templates (`assets/mrpl_template.dotx`) with approval signature blocks and formatted bookmark slots — executive-ready files, not plain text. Deliverable formats are `.docx` and `.xlsx` only; `.pptx` and signed-PDF are cut as stretch goals off the 30-hour critical path.
Template exporter reference (v5.0 restored fenced block):

```python
import re
from docx import Document
from docx.shared import Inches

CITE_RE = re.compile(r"\[SOP-REF §\d+\.\d+ p\.\d+\]")

def render_deliverable(template="assets/mrpl_template.dotx", out="artifacts/memo.docx",
                       slots=None, citations=None, pictures=None):
    doc = Document(template)                        # pre-styled corporate .dotx
    for para in doc.paragraphs:                     # formatted bookmark slots
        for key, value in (slots or {}).items():
            if f"[[{key}]]" in para.text:
                full_text = "".join(run.text for run in para.runs)
                full_text = full_text.replace(f"[[{key}]]", value)
                for run in para.runs:
                    run.text = ""
                if para.runs:
                    para.runs[0].text = full_text
    for cite in citations or []:                    # citation contract gate
        assert CITE_RE.fullmatch(cite), f"unresolvable citation blocked: {cite}"
    for path in pictures or []:                     # P&ID thumbnails + trend chart
        doc.add_picture(path, width=Inches(4.8))
    doc.save(out)                                   # written only after HITL approve
    return out
```
